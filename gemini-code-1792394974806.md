# Pakistan Opportunity Finder

A lightweight, secure, mobile-friendly static web application built to aggregate verified official Pakistani government portals, scholarships, youth programs, and skills training initiatives.

## Features
- **Searchable Categories**: Scholarships, Government Jobs, Admissions, Youth Programmes, and Skills Training.
- **Official Source Links**: Direct links to trusted `.gov.pk` and institutional portals.
- **Transparent Status Labels**: Clear distinction between verified open portals and unverified/closed cycles.
- **Anti-Scam Security Guidance**: Prominent alerts reminding users that official government applications never charge fees through personal mobile wallets.
- **Zero Dependencies**: Pure HTML, Tailwind CSS, and Vanilla JavaScript with no login system or paid APIs required.

## Local Testing
1. Clone or download this repository.
2. Open `index.html` in any modern web browser.

## Deployment Instructions (Free Hosting via GitHub Pages)
1. Create a new public repository on GitHub (e.g., `pakistan-opportunity-finder`).
2. Upload `index.html` and `README.md` to the main branch.
3. Go to your repository **Settings** > **Pages**.
4. Under **Build and deployment**, select **Branch: main** and folder **/ (root)**, then click **Save**.
5. Within 1 minute, your live website URL will be generated by GitHub.
